# Thư Mục Nhạc Nền 11A2 (`assets/music/`)

Nơi lưu trữ file nhạc nền cho website.

### Cách sử dụng:
1. Thả file nhạc mong muốn vào đây và đổi tên thành: `bgm.mp3` (Đường dẫn: `assets/music/bgm.mp3`).
2. Định dạng khuyến nghị: `.mp3` (bitrate 128kbps - 192kbps, Lofi Piano, Acoustic nhẹ nhàng).
3. **Lưu ý đặc biệt:** Nếu chưa có file `bgm.mp3`, hệ thống đã tích hợp sẵn **Web Audio API Lofi Piano Synthesizer Fallback** tự động sinh giai điệu piano Lofi ấm áp và du dương 100% offline, luôn luôn có nhạc mà không bị gián đoạn!
